# 番茄免费小说 去广告（GKD 订阅插件）

让你在安卓手机上继续用官方番茄小说 APP，但广告被自动关掉。
原理：通过安卓**无障碍服务**识别广告控件，自动帮你点【跳过】/【x】/【不感兴趣】。
**不修改番茄 APP 本体、不需要 root、不改安装包**，规则全部来自开源社区已验证的快照。

## 一、调研结论：现成的开源方案

| 方案 | 说明 | 现状 |
| --- | --- | --- |
| [GKD](https://gkd.li)（gkd-kit） | 开源（GPL）、基于无障碍+高级选择器的自动点击工具，规则用"订阅"形式分发 | ✅ 活跃维护，本方案的宿主 |
| [gkd-kit/subscription](https://github.com/gkd-kit/subscription) | GKD 官方订阅，含番茄 8 组规则 | ⛔ 已停止维护（2024-05 归档），规则仍可正常使用 |
| [AIsouler/GKD_subscription](https://github.com/AIsouler/GKD_subscription) | 知名第三方订阅，含番茄 11 组规则（开屏/阅读页/全屏/签到弹窗等） | ⚠️ 已停止维护，但规则仍可用 |

其他路线对比：修改版 APK（去广告破解版）——需关闭系统校验、来源不可信、版本永远落后官方，**不推荐**；LSPosed 模块——需要 root/刷机，门槛高。GKD 方案免 root、随官方版本更新规则，是社区主流做法。

## 二、安装步骤（约 5 分钟）

1. **安装 GKD**：手机浏览器打开 <https://gkd.li> 下载正式版（v1.12.1+），或去 [GitHub Releases](https://github.com/gkd-kit/gkd/releases) 下载。
2. **开启无障碍**：打开 GKD，按提示在系统设置里授权无障碍服务；再到系统设置里给 GKD 关闭电池优化/允许后台运行（否则会被杀后台导致不生效）。
3. **导入本订阅（二选一）**：
   - **方式 A（推荐）**：GKD → 底部「订阅」→「本地订阅」→「应用规则」→ 把本目录 **`番茄小说-本地订阅粘贴.json5`** 的全部内容复制粘贴进去 → 保存。
   - **方式 B（远程订阅，可自动更新）**：本仓库已托管该文件，GKD →「订阅」→ 右上角「+」→ 粘贴下面这个订阅链接：
     ```
     https://raw.githubusercontent.com/rranbo7777777/gkd-fanqie-subscription/main/%E7%95%AA%E8%8C%84%E5%B0%8F%E8%AF%B4%E5%8E%BB%E5%B9%BF%E5%91%8A.json5
     ```
     （即仓库里的 `番茄小说去广告.json5`；以后更新文件推送后，手机端 GKD 会自动检查更新。）
4. **确认规则已启用**：在本地订阅的应用规则里能看到「番茄免费小说」及 10 个开启的规则组（「看视频自动领奖励」默认关闭）。
5. 打开番茄小说测试：启动时的开屏广告应自动点掉；阅读时页面中间/底部的广告卡片会被自动关闭（分段广告会先点【反馈】再点【不感兴趣】，约 1~2 秒）。

## 三、各规则组作用一览

| 规则组 | 作用 | 默认 |
| --- | --- | --- |
| 开屏广告 | 启动 APP 时自动点【跳过】（番茄专属按钮 + 通用兜底） | 开 |
| 卡片式广告-阅读页横幅 | 点掉阅读页/首页嵌的广告卡片【x】（6 种布局） | 开 |
| 分段广告-阅读页信息流 | 点【反馈】→【不感兴趣】，或点卡片【x】 | 开 |
| 全屏广告-阅读页 | 关掉阅读页弹出的整屏广告 | 开 |
| 首页悬浮广告 | 关掉右下角悬浮【x】 | 开 |
| 阅读页-关注作者弹窗 | 自动关闭关注作者弹窗 | 开 |
| 运营弹窗 | 关闭电商惊喜券 / 一分购 / 抽奖 / 签到弹窗 | 开 |
| 更新提示 | 自动点【以后再说】 | 开 |
| 评价提示 | 关闭求好评 / 点评此书弹窗 | 开 |
| 通知权限弹窗 | 自动点【取消】拒绝推送 | 开 |
| 看视频自动领奖励 | 看完激励视频自动领奖（可能提前关视频导致奖励无效） | **关** |

## 四、常见问题

- **某个广告没被关掉**：番茄版本更新后布局可能变化。GKD →「媒体」/快照功能可截取当前页面控件树（快照），之后把规则加上对应选择器即可；或同时添加官方订阅兜底（下面第 5 条，该订阅已停止更新但规则仍可用）。
- **完全不生效**：99% 是无障碍被系统回收了。重新开启无障碍，并把 GKD 加入最近任务锁定 / 电池白名单。
- **想要双保险**：GKD「订阅」→「+」→ 添加官方订阅 `https://registry.npmmirror.com/@gkd-kit/subscription/latest`，与本订阅共存不冲突，官方订阅还会覆盖其它所有 APP 的广告（该订阅已停止更新，规则停留在归档时的版本，但仍可用）。
- **会误点吗**：所有规则都限定了文案、尺寸、控件层级，且开屏规则只在启动 10 秒内生效。若某条规则误点，在 GKD 里单独停用该组即可。
- **说明**：本插件仅自动"点关闭按钮"，属于个人使用的辅助自动化；不去除"看视频解锁章节"这类付费/激励逻辑（那是内容方免费模式的门槛），实验组的自动领奖默认关闭。
